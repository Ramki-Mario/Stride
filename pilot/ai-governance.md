# STRIDE AI Governance

# Core Principle

AI assists engineering.
AI does NOT control architecture.

---

# Mandatory AI Rules

- Always read relevant agent files before implementation
- Never bypass architectural boundaries
- Never directly use DbContext inside controllers
- Never bypass tenant isolation
- Never expose secrets
- Never generate uncontrolled large codebases
- Always preserve modular consistency
- Always build incrementally
- Always update current-status.md after significant progress

---

# AI Context Strategy

Use:
- scoped prompts
- focused implementation tasks
- relevant architectural files only

Avoid:
- giant prompts
- uncontrolled scaffolding
- architecture drift
